Давай перейдем к организации экономики



Одна расходуемая валюта — частички коллекций:

\- Изначально на каждой картинке 0 элементов коллекций

\- При сборе одной линии блоков, игроку дается 1 элемент коллекции.

\- Кол-во полученных элементов коллекции множится на комбо, в зависимости от размера комбо.

\- Частички принадлежат к каждой отдельной коллекции. То есть за сбор одной линии, игрок получает случайный тип частички.\
&#x20;\- При получении частичка улетает в картинку в коллекциях.\
&#x20;\- Для полного сбора коллекции игроку нужно собрать 100 частичек.\
&#x20;\- Вероятность выпадения частичек для разных коллекций разная. Для первой коллекции — 50%, для второй коллекции — 40%, для третьей коллекции — 10%.\
&#x20;\- Картинки в коллекциях имеют под собой прогресс бар с сундуком на конце. После сбора всех частичек коллекции, игроку показывается кнопка “забрать”, для открытия сундука.\
&#x20;\- Сундук под каждой из картинок имеет разный визуал — обычный, редкий и легендарный

- визуал коллекции полупрозрачный и закрыт. Открывается картинка постепенно в зависимости от кол-ва собранных частичек



Собери прототип визуальный и механический, а там дальше будем вносить правки. Механику сундука и открытия скинов пока не проробатываем.
