# Этап 4 — скины и открытие сундуков

## Изменения
- Добавлены 3 скина: Терракота (обычный), Океан (редкий), Аврора (легендарный). Всего 6.
- Изначально разблокирован только Лотос. Переход v1/v2 → v3 сохраняет валюту, сбрасывает старые демонстрационные разблокировки. Полученные в v3 скины сохраняются.
- «Забрать» списывает 100 частичек исходной картинки. Выпадает один скин. Дубликат даёт 25 частичек только исходной картинки. Стартовый скин входит в пул.
- Шансы обычного/редкого/легендарного скина: обычный сундук 75/20/5, редкий 35/45/20, легендарный 10/50/40. Внутри редкости равные шансы, без защиты от дубликатов.
- Транзакция сохраняется до анимации. Двойное нажатие не списывает повторно. Новый скин можно применить сразу или позже.
- Собранная картинка остаётся полностью открытой после списания; шкала показывает части для следующего сундука. Избыток сохраняется.
