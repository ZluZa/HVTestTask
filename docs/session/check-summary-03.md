# Проверки этапа 3: экономика коллекций

## Реализовано
- Три отдельных баланса одной типизированной валюты, начальные значения 0.
- Одна линия даёт 1 × текущий комбо частичек; отдельный независимый выбор типа за каждую линию: 50% / 40% / 10%.
- Сохранение сразу при начислении, миграция настроек v1 → v2, защита от некорректных сохранений.
- Закрытая полупрозрачная картинка, проявление мозаики 10×10, прогресс 0–100, три разных SVG-сундука и кнопка «Забрать» при готовности.
- Избыточные частички сохраняются в запасе. Шансы после завершения картинки не меняются.
- Полёт в видимую картинку либо её миниатюру-уведомление, если картинка вне экрана. Поддержаны параллельные полёты и reduced motion.
- «Забрать» показывает готовый сундук без списания и без награды. Механика открытия/скинов по запросу пока не реализована.

- stage3-browser-01.log: 16 браузерных сценариев успешно, 9 для экономики и 7 регрессионных сценариев игры.
- Реально проверены полёты каждого из трёх типов, 99 → 100, частичное проявление маски, избыток 104 → прогресс 100 + запас 4, закрытый/готовый сундук, отсутствие списания и выдачи скина, перезагрузка, несколько незавершённых полётов, мобильный touch без самопрокрутки, reduced motion и испорченный JSON.

- Вручную просмотрены PNG закрытой/частичной коллекции, редкого и легендарного сундуков, мобильного полёта. Файлы stage3-economy-1789506043517-*.png.

- Mobile — Chrome touch-эмуляция, не физическое устройство.
- Продолжение партии свыше 18 ходов сохранено.
