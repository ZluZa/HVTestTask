# Ежедневный уровень — проверка 2026-09-16

Реализованы баннер с таймером, три типа целей, раскладки от даты, лимит ходов, повторные попытки, бесплатный редкий сундук один раз на дату, восстановление основной партии после выхода/награды. Дубликат даёт 25 частичек «Маяка».

## Результаты

- TypeScript: без ошибок.
- Vitest: 45 тестов прошли. Проверена решаемость и уникальность 365 раскладок, все типы целей, границы ходов, синие клетки на пересечениях, сохранение награды и миграция.
- Готовая сборка Vite: успешно, JS `index-DK3QdIpT.js`, CSS `index-BqU9M2Xd.css`.
- Browser: 27/28 прошли общим прогоном готовой сборки. Один тест clear-wave упал до проверки игры из-за попытки перевести виртуальные часы назад. После фикса явного времени этот тест отдельно прошёл (1/1). Все 28 сценариев в итоге проверены успешно.
- Все 6 новых браузерных сценариев ежедневного режима прошли: победа по каждой цели, награда/экипировка, восстановление партии, перезагрузка, повторная попытка после проигрыша, смена даты во время уровня, выход и одинаковая раскладка при повторном входе.
- Просмотрены снимки desktop, daily 390 px и основной экран с баннером 320 px. Горизонтального переполнения нет; смартфон проверен эмуляцией, не физическим устройством.

Для финального браузерного прогона использовалась отдельная статическая сборка на 127.0.0.1:48173, чтобы исключить влияние перезагрузок dev-сервера при изменении файлов. Сборка совпадает с итоговой dist.

## Ограничения прототипа

Дата устройства, местная полночь, локальное сохранение наград. При перезагрузке игровая попытка начинается заново. Защита календаря и наград на сервере отсутствует.
