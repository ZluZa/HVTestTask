# Журнал тестового задания

- Начало: 2026-09-15T20:23:37Z (23:23:37 МСК), подтверждено реальными часами.
- Общий лимит: 60 минут активной работы для трёх промптов.
- Промпты сохранять новыми файлами `prompt-02.txt`, `prompt-03.txt`; уточнения — отдельными файлами.
- Публичные сообщения и результаты проверок добавлять через `node scripts/log.mjs TYPE`, текст передаётся в stdin. Старые строки не изменять.
- Время `recordedAt` — время фиксации в журнале. Для ранних сообщений оно позднее отправки, что явно записано; время не подменяется задним числом.
- Для каждой новой проверки использовать новый номер `.log` и новое имя снимка. Сохранять неудачные проверки вместе с успешными.
- В `active-segments.jsonl` добавлять начало/конец и длительность этапов. Ожидание между промптами не включать. Перед следующим этапом прочитать уже потраченное время.
- Проверять цепочку: `previousHash` равен SHA-256 точной предыдущей строки без перевода строки. Это локальная проверка целостности, не внешнее удостоверение времени.
